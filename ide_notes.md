# IDE vs CLI notes

1. В VS Code удобно смотреть историю коммитов и diff файлов в панели Source Control.
2. Быстро удобно проверять изменения по файлам и смотреть контекст без запуска терминала.
3. Возможность интеграции с GitLens и визуальным просмотром слияний и авторства строк.

Что удобнее в терминале:
- сложные Git-команды и rebase, а также сценарии с множеством веток и глубокими историческими операциями.
