# Сравнение Git и SVN

1. Почему ветвление в Git дешевле, чем в SVN?
   В Git ветки — это указатели на коммиты, а не отдельные копии репозитория. Создание, переключение и слияние веток почти мгновенные. В SVN ветки обычно представляют собой отдельные каталоги/копии, которые тяжелее поддерживать и проверять.

2. Можно ли в SVN сделать коммит без интернета?
   Да, локальный SVN-репозиторий можно использовать без доступа к удаленному серверу, если работа ведётся в локальной копии. Но для синхронизации с центральным репозиторием нужен доступ к серверу.

3. Когда SVN может быть предпочтительнее Git?
   SVN может быть удобен в небольших командах, когда нужен простой централизованный workflow, меньше сложность ветвления и нет потребности в развитых распределённых сценариях.
